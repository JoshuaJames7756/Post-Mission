# Calendar Implementation Plan

> **For agentic workers:** Execute inline one task at a time. Each task ends with a focused verification checkpoint; keep every migration explicit and owner-scoped.

**Goal:** Deliver the first working Calendar slice: private persisted events, correct all-day and zoned-time handling, and a responsive month view.

**Architecture:** Hono routes authenticate through the existing Clerk middleware, validate with shared Zod schemas, and call owner-scoped services/repositories backed by Drizzle and Neon. React consumes those routes with the existing TanStack Query client. The month view is the first increment; week/day views and links to not-yet-built People, Places, and Notes follow in later slices.

**Tech Stack:** Existing React, Vite, TypeScript, Hono, Zod, Drizzle, Neon, TanStack Query, Lucide, Vitest, Cloudflare Workers.

**Spec:** `docs/superpowers/specs/2026-10-24-calendar-design.md`, derived from the user-provided Post Mission master brief.

## Global Constraints

- Keep the browser disconnected from Neon; all persisted operations use `/api/v1`.
- Obtain identity only from a verified Clerk session and scope every resource by owner.
- Validate all inputs on the server and preserve date-only versus instant semantics.
- Do not add recurrence, reminders, paid map services, sample personal data, or automatic migration execution.
- Keep secrets in private Worker bindings and do not deploy without explicit authorization.

## Risks and Mitigations

| Risk | Impact | Mitigation |
|---|---|---|
| DST gaps or folds map local wall times to zero or multiple instants | Incorrect event times | Resolve against IANA rules; reject gaps and require an explicit offset for folds; test transition cases. |
| All-day dates shift by device zone | Event appears on the wrong day | Persist and render all-day values as calendar dates only. |
| Cross-user associations expose records | Privacy breach | Composite owner-scoped foreign keys and owner filters in every repository operation. |
| Calendar views grow beyond one implementation slice | Delayed usable product | Ship the month vertical slice first; continue week/day and entity links as separate increments. |

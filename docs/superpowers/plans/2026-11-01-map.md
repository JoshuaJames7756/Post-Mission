# Map Implementation Plan

> **For agentic workers:** Execute one task at a time and keep database changes explicit and owner-scoped.

**Goal:** Deliver private saved places with map/list views, safe event links, and a working list fallback.

**Architecture:** Authenticated Hono routes validate shared Zod schemas and call owner-scoped Drizzle services. React queries those routes. Leaflet renders client-side markers only after an explicit user action; a provider interface isolates the tile source.

**Tech Stack:** Existing React, TypeScript, Hono, Zod, Drizzle, Neon, TanStack Query, Leaflet 1.9.4, OpenStreetMap Standard tiles, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-01-map-design.md`

## Global Constraints

- Keep place data private and verify owner on each API operation.
- Do not geocode or send labels, addresses, notes, or account identifiers to the tile provider.
- Load OSM tiles only after an explicit user choice; keep visible attribution and respect caching.
- Keep the place list available when map tiles fail or the user declines map loading.
- Never prefetch tiles or promise free hosted map availability.
